本文件示範如何用 v72.html 的計分演算法（`calculateAffinityScore`），找出跟「李佳穎」配對到滿分 **100** 的三字單姓公司名。

可執行驗證：

```bash
python3 tools/verify_v72_score.py
```

腳本實作對照 v72.html 第 704–812 行；五格計算對照第 501–503 行（三字單姓）。

## 配 100 分的數學條件

設公司 B 為三字單姓，筆劃 $(s_1, s_2, s_3)$。五格：

- $tian = s_1 + 1$
- $ren = s_1 + s_2$
- $di = s_2 + s_3$
- $zong = s_1 + s_2 + s_3$
- $wai = zong - ren + 1$

達 100 分的最強路徑是**雙向直接貴人 + 總格平宮 + 雙方五行俱全**：

- $B.ren = A.di$（B→A 直接貴人）
- $B.di = A.ren$（A→B 直接貴人）
- $B.zong = A.zong$（總格平宮）

聯立解：

| 版本 | $A.ren$ | $A.di$ | $A.zong$ | $\Rightarrow$ $(s_1, s_2, s_3)$ |
|:---:|:---:|:---:|:---:|:---:|
| A | 16 | 24 | 32 | **(16, 8, 8)** |
| B | 14 | 26 | 32 | **(18, 8, 6)** |

兩種結構下公司本身的五格也都剛好五行俱全 → 觸發「雙方五行俱全 +4」與「五行俱全加成 +5×2」。

```
分數 = 40 (base) + 20+5 + 20+5 + 6 + 8 + 4 = 108  → cap → 100
```

Version B 額外帶有 $reduce(A.zong)=5 = reduce(B.di)=5$ 的「暗小人 -8」副作用，但 $40+25+25-8+6+8+4 = 100$ 剛好夠。

## 補充：為何沒有「一個公司同時配兩版都 100」

兩版的 $A.ren$（16 vs 14）、$A.di$（24 vs 26）皆不同，雙向直接貴人要求的 $B.ren, B.di$ 也跟著不同 → 同一個公司不可能同時滿足兩版的雙向直接貴人。

如要折衷：
- $(16, 8, 8)$ 對 Version A = 100，對 Version B 通常落在 60–80。
- $(18, 8, 6)$ 對 Version B = 100，對 Version A 通常落在 60–80。

實際分數隨字而異（陰陽盤可能再 ±2），用 `tools/verify_v72_score.py` 套上自己的字組合即可即時驗算。

## 字選擇備註

- 凡屬「立刀旁、犯禁字、生僻字」的字未列入候選。
- 第一字（16 或 18 劃）取較常見、語感正向的字：學、錦、璇、鎮、蕭、豐。
- 中間字（8 劃）多為陽光意象：沛、東、宜、和、青、昕。
- 末字（8 / 6 劃）以收結感字：和、昕、青、宇、旭、吉。
- 三字組合語感不拘，因為使用者僅要求數學成立。如要做實際公司名，再從本文件腳本的 brute-force 結果（Version A 共 5054 組、Version B 共 3211 組）挑語意合適者。
