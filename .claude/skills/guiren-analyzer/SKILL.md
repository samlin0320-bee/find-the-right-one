# 貴人合盤分析器

姓名學雙人合盤的核心關係判斷：A 對 B 是貴人還是小人？兩人之間有沒有平宮？是否觸發「護貴人」或「合盤上吉／上凶」？本 skill 包含完整規則 + Python 工具。

## 觸發條件

使用者問到下列任一概念就用這個 skill：

- 「XX 是不是我的貴人／小人」
- 「我和 XX 合盤如何」「兩人緣分」
- 直接貴人 / 間接貴人 / 明小人 / 暗小人 / 平宮
- 護貴人 / 合盤上吉 / 合盤上凶
- 化氣相同 / 人格相同 / 地格相同 / 總格相同
- 「老闆會不會拖累我」「對方是不是來成就我的」

> 不適用：單人五格分析、流年衝剋（→ 用 `liunian-analyzer`）。

## 輸入需求

兩人各一組五格筆劃：

- **天,人,地,外,總**（5 個整數）
- （選用）姓名

判定只用 **人 / 地 / 總** 三格；天 / 外 接收但忽略。但建議使用者連天/外都給，便於同時做其他姓名學分析。

## 規則摘要（口頭推理也夠用）

### 1. 化氣（reduce）

把筆劃反覆拆位相加直到 1-9：

```
10 → 1+0 = 1
15 → 1+5 = 6
24 → 2+4 = 6
25 → 2+5 = 7
99 → 9+9=18 → 1+8 = 9
```

### 2. 貴人線（看「人格 → 地格」方向）

| 條件 | 判定 | 力量 |
|---|---|---|
| **A.人格 == B.地格** | A 是 B 的**直接貴人** | 1x（主動幫忙、直接給資源） |
| **reduce(A.人格) == reduce(B.地格)** | A 是 B 的**間接貴人** | **10x**（化氣相同、介紹資源） |

> 課程原話：「間接貴人的力量是直接貴人的十倍」。
> 直接與間接 **獨立判定，可同時成立**（兩條都列）。

### 3. 小人線（看「總格 → 地格」方向）

| 條件 | 判定 |
|---|---|
| **A.總格 == B.地格** | A 是 B 的**明小人**（直接拖累 B） |
| **reduce(A.總格) == reduce(B.地格)** | A 是 B 的**暗小人**（無心之過，B 要幫 A 擦屁股） |

### 4. 平宮（同數相等，只看人/地/總，**天/外不看**）

| 平宮 | 意義 |
|---|---|
| 人格 = 人格 | 思維、個性相近 |
| 地格 = 地格 | 感情、事業觀相近 |
| 總格 = 總格 | 人生終極目標一致（最重要） |

### 5. 衍生旗標

| 旗標 | 條件 | 解讀 |
|---|---|---|
| **護貴人** | 雙向都成立**間接貴人**線 | 課程：「兩條就超強」 |
| **合盤上吉（互為貴人）** | A→B 與 B→A 至少各有一條貴人線 | 雙方都受益 |
| **合盤上凶（互為小人）** | A→B 與 B→A 都有小人線 | 雙方互相拖累，建議遠離 |
| **亦正亦邪** | 同一方向同時有貴人 + 小人 | 那個人會幫你也會拖你 |
| **五行俱全加成** | 貴人方五格五行（金木水火土）俱全 | 貴人之力 100% 發揮 |

> 五行對照（個位數）：1,2 木 / 3,4 火 / 5,6 土 / 7,8 金 / 9,0 水

## Worked Example：李佳穎 vs 王大明

李佳穎 9/16/24/17/32（五行俱全），王大明 11/15/24/9/33。

執行：

```bash
python3 ~/.claude/skills/guiren-analyzer/guiren.py \
    --a "李佳穎:9,16,24,17,32" --b "王大明:11,15,24,9,33"
```

**判定結果**：

- 王大明 **人格 15 化氣 6** = 李佳穎 **地格 24 化氣 6** → **王大明是李佳穎的間接貴人**（10x 力道）
- 王大明 **總格 33 化氣 6** = 李佳穎 **地格 24 化氣 6** → **王大明同時是李佳穎的暗小人**
- 兩人 **地格 24 = 24** → **地格平宮**（感情／事業觀相近）

**結論**：`⚖️ 王大明 對 李佳穎 亦正亦邪：是 李佳穎 的「間接貴人」，同時也是 李佳穎 的「暗小人」。`

> 解讀方式：王大明的力量是「間接貴人」（化氣，10x）與「暗小人」並存——
> 會透過人脈介紹資源給李佳穎，但也會無心地讓她得收尾。可保持往來但別把關鍵決策完全交給他。

### 結論句格式規範

亦正亦邪、單向、混合等狀況 **一律列出實際命中的標籤**，不只說「貴人」「小人」：

| 情境 | verdict 範例 |
|---|---|
| 亦正亦邪（B→A 間接貴人 + 暗小人） | `⚖️ B 對 A 亦正亦邪：是 A 的「間接貴人」，同時也是 A 的「暗小人」。` |
| 亦正亦邪（A→B 雙線都命中） | `⚖️ A 對 B 亦正亦邪：是 B 的「直接貴人、間接貴人」，同時也是 B 的「明小人、暗小人」。` |
| 單向貴人 | `👼 單向：A 是 B 的「直接貴人、間接貴人」（B 受益較多）。` |
| 單向小人 | `⚠️ 單向小人：A 是 B 的「明小人、暗小人」，會拖累 B。` |
| 混合（互貴 + 單向小人 等） | `🔀 混合關係：A→B 是「直接貴人」；B→A 是「間接貴人、明小人」。` |

## 觸發範例

User：「我是 9/16/24/17/32，我老闆是 11/15/24/9/33，他是我的貴人嗎？」
→ 直接執行 `--a ...你的五格 --b ...老闆的五格`，標明對方在 B 位以對應「對方→我」方向

User：「我和 XX 適合一起創業嗎？」
→ 跑工具看是否合盤上吉、是否有護貴人、總格平宮（目標一致）

User：「兩人化氣相同會怎樣？」
→ 解釋「化氣相同 = 間接貴人 / 暗小人」（看的是人格還是總格 vs 對方地格）

## 注意事項

- **方向重要**：A→B 與 B→A 是兩條獨立判定線，必須兩邊都跑
- **直接與間接獨立**：同數時（如 24 vs 24）同時觸發直接 + 間接，兩條都算
- **天格、外格不參與**貴人 / 小人 / 平宮判定；要看天/外請用 `liunian-analyzer`
- **「貴人 + 小人」同一人同時成立**並非錯誤，是「亦正亦邪」，應如實呈現而非二選一
- 五行俱全僅影響「貴人之力是否 100% 發揮」，並不會把小人轉成貴人
- 結果僅供姓名學參考；實際關係仍需綜合判斷
